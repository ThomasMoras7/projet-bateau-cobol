# Search Account Balance API

## Overview
Retrieves and displays the balance of a specific account using its ID.

## Description
This program prompts the user for an `ACCOUNT-ID`, searches the indexed `ACCOUNTS.DAT` file, and displays the account details (name and balance) if found.

## Input
- `WS-SEARCH-ID`: The ID of the account to search for.

## Output
- If found: Displays account name and balance.

## Execution
Compile and run `search-account-balance.cbl`.
